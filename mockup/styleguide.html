Contrast verification

Ratios computed with the WCAG 2.1 relative-luminance formula, not estimated by eye. WCAG AA requires 4.5:1 for normal text and 3:1 for large text (18.66px bold / 24px regular) and UI components. AAA requires 7:1.

The headline result: the primary gold cannot be used for text on light backgrounds.

#D4AF37 on #F7F7F5 is 1.96:1. That fails AA for normal text, fails AA for large text, and fails the 3:1 threshold for UI components. It is not a borderline miss — it is roughly 2.3× short of the requirement. The same gold on the near-black #16171A passes at 8.52:1, comfortably clearing AAA.

The palette already contains the fix. #6E561A (gold-deep) on #F7F7F5 is 6.51:1, which clears AA for all text sizes. The system below encodes this as a hard rule via two aliases: --accent-on-dark and --accent-on-light. Use the alias, never the raw gold.

What this looks like in practice

Gold on a light surface, done correctly

This heading uses --accent-on-light (#6E561A) at 6.51:1. Body copy uses --muted at 8.67:1. The button below drops to the deep gold rather than the primary. Inline links take the same treatment.

For contrast, this text is the raw primary gold: #D4AF37 at 1.96:1 — barely legible, and non-compliant. That is the failure this system prevents.

Prune before build

The live theme.json also declares the twelve stock WordPress preset colours (#f78da7, #cf2e2e, #ff6900 and friends). They clutter the editor colour picker and invite off-brand choices. Remove them when the tokens land in the theme.

Typography

Three families, unchanged from the live site — the existing system is deliberate and worth keeping. Playfair Display carries editorial weight on headings, Inter handles body and UI, JetBrains Mono is reserved for numbers, metrics and code.

Interactive states

Every interactive element declares all five states. The focus ring is --gold-light at 2px with a 2px offset, which reads at 10.32:1 against the dark surface — focus must never be removed without an equally visible replacement.

Inline link

Body copy with an inline link in the primary gold, underlined with a 3px offset so the underline never collides with descenders. Underlines stay on — colour alone is not an accessible link affordance.
