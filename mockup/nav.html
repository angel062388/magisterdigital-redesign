How this is built

  1. StackPlain HTML and CSS. No WordPress, no build step, no dependencies.
  2. TokensEvery colour, size, radius and shadow is a CSS custom property in tokens.css, shared by every page.
  3. TypePlayfair Display, Inter and JetBrains Mono — the three already in use on the live site.
  4. HostingGitHub Pages, served from main. Push and the link updates.
  5. CrawlingEvery page carries noindex, nofollow while in review.
