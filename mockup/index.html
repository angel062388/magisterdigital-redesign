One finding you should read before anything is designed

The primary gold #D4AF37 scores 1.96:1 on the off-white surface. That fails WCAG AA for text of any size, and fails the 3:1 floor for UI components too. On the near-black it passes at 8.52:1. The design system resolves this with two aliases, --accent-on-dark and --accent-on-light, so the raw gold can never reach a light surface by accident. Full matrix on the design system page.

How this is built

  • Plain HTML and CSS. Open any file directly in a browser and it works.
  • Every colour, size, radius and shadow is a CSS custom property declared once in :root.
  • Fonts are the three already in use on the live site: Playfair Display, Inter, JetBrains Mono.
  • Served by GitHub Pages from this repository. Push to main and the link updates.
  • Pages carry noindex so the mockup cannot be crawled while it is in review.
